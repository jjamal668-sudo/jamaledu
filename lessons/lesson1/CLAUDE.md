# إحاطة لجلسة ذكاء اصطناعي قادمة — عرض الدرس الأول

## البناء (الإصدار الثاني — نوفمبر ٢٠٢٦)
- `index.html` + `css/show.css` + `js/lesson.js` (البيانات: عناوين الضغطات وملاحظات المعلم) + `js/show.js` (المحرك). شاشة المعلم `presenter.html`.
- مسرح ثابت 1600×900 يُكبَّر ليملأ الشاشة. كل شريحة `<section class="slide" data-id data-bg data-tr>`، والعناصر التي تظهر بالضغط عليها `data-f="n"`، والتي تختفي `data-o="n"`. عدد ضغطات كل شريحة = طول مصفوفة `t` في lesson.js (يجب أن يطابق أكبر data-f).
- الحالة = رقم الضغطة فقط؛ الرجوع والقفز يعطيان الصورة نفسها (تم فحصها لكل الضغطات).
- الانتقالات: slide / zoom / iris / curtain / fade بـ Web Animations. المؤثرات اللحظية `data-fx="burst|slam"` تعمل عند التقدم فقط.
- الأداء: transform / opacity / clip-path فقط؛ لا filter ولا mix-blend-mode؛ الشرائح غير الظاهرة display:none. القياس: ~٥٧ إطارًا/ث (كان ~٣٨ في القصة المصوّرة).
- الإصدار السابق (القصة المصوّرة) محفوظ في `comic.html` و`comic-presenter.html` مع ملفاته (comic.js, engine.js, deck.js, stage.css).

## قواعد المعلم (لا تخالفها)
- كل معلومة من كتاب `3652.pdf` فقط، صفحات ١٦–١٨ (PDF ١٧–١٩). سجّل أي نص جديد في `docs/sources.md`.
- عنوان الدرس في أول ضغطة، واسم المنصة «© منصة جمال التعليمية» بجانب التاريخ واليوم أعلى الشاشة دائمًا، وزر ملء الشاشة.
- فصحى، بلا إيموجي، ولا إيموجي بجانب اسم شيخ أو حاكم.
- لا تعرض المعيار أو المؤشرات على الشاشة.
- الريموت: كل ضغطة «التالي» تكشف عنصرًا واحدًا بالترتيب، ثم تنتقل للوحة التالية.
- البطاقات القلّابة ثلاثية الأبعاد (rotateY + backface-visibility) هي طريقة الكشف المفضلة.
- يعمل على آيباد Safari وشاشة الصف؛ بلا إنترنت (لا روابط خارجية وقت التشغيل).
- لا تغيّر شيئًا في الموقع الحي قبل أن يقول المعلم «تم».

## قبل أن تقول «انتهيت»
1. `python3 -m http.server 8766` من مجلد الموقع.
2. `python3 lessons/lesson1/tools/dev/check.py` (أخطاء الكونسول، الرجوع، القفز=التنقل، مقارنة بكسلية، لقطات منتصف الحركة في /tmp/l1check/mid_*).
3. انظر إلى لقطات منتصف الحركة لا النهايات فقط.
4. `bash lessons/lesson1/tools/snapshots.sh` لتجديد اللقطات.
5. حدّث README و`docs/sources.md`.
